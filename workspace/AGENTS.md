# 작업 환경 안내 (AGENTS.md)

이 파일은 에이전트가 시작할 때 읽어 시스템 프롬프트에 덧붙입니다.
(Claude Code 의 CLAUDE.md, 여러 에이전트 도구의 AGENTS.md 와 같은 역할)

## 작업 폴더
- 작업 폴더(workspace)는 git 저장소(spring-ai 프로젝트) 안의 하위 폴더입니다.
- 저장소 루트와 프로젝트 소스(build.gradle.kts, src/)는 상위 폴더(../)에 있습니다.
  작업 폴더 밖이므로 파일 도구로는 읽을 수 없고, 명령 실행 도구로는 사용자 승인이 필요합니다.
- git 명령은 작업 폴더에서 실행해도 저장소 전체를 대상으로 동작합니다.

## 명령 실행 도구 사용법
- 셸이 아닙니다. 파이프(|), 와일드카드(*), 명령 연결(&&, ;), 리다이렉트(>)를 쓰지 말고 명령 하나로 해결하세요.
- 폴더 전체를 대상으로 할 때는 와일드카드 대신 -r 옵션과 폴더 이름(. 또는 notes)을 쓰세요.

## 목적별 명령
| 목적 | 명령 |
|---|---|
| 단어가 들어간 파일 찾기 | grep -rl "단어" . |
| 단어가 나온 횟수 (파일별) | grep -rc "단어" . |
| 파일 하나의 줄 수 | wc -l 파일 |
| 폴더 안 모든 파일의 줄 수 | grep -rc "" 폴더 |
| 현재 브랜치 | git branch --show-current |
| 최근 커밋 | git log --oneline -5 |
| 변경된 파일 | git status --short |
| 변경 내용 | git diff |
